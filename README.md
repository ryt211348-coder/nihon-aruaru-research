# 日本あるある 企画リサーチ（共有版）

日本のSNSで単体バズした**一般人のオーガニック投稿**を集め、感情の被らない5本セットにして
「この5つをくっつけたら1本の詰め合わせショートになります」を提示するリサーチツールの共有版。

- 素材は TikTok / Instagram のみ。プロのクリエイターの企画ショート・転載まとめ・
  競合の完成品は `organic=0` として除外している
- 各カードをクリックすると元投稿を開ける
- 素材の一括DLは手元のMacでのみ動作（共有版では非表示）

※データはスナップショット。更新は `python3 scripts/export_site.py --public --push`
